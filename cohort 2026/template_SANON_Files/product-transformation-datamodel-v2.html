06

Decision support matrix

When something goes wrong, what data does the manager need to make decisions? This matrix maps triggers to required data and recommended actions.

QC failure at any stage batch_id, stage, parameter, measured_value, spec_range, failure_count Hold batch → Investigate → Rework or Reject
Moisture above target (CCP breach) batch_id, current_moisture, drying_time, temperature_log, energy_source Extend drying → Re-test → Document corrective action
Stage bottleneck detected stage_name, batch_count, avg_duration, equipment_status, operator_count Reallocate resources → Adjust schedule → Escalate if >4h
Yield drop below threshold batch_id, input_weight, output_weight, yield_pct, loss_breakdown Analyze loss source → Adjust process → Train operators
HACCP compliance gap ccp_point, requirement, evidence_doc, status, auditor_notes Document gap → Implement corrective action → Re-audit
Export deadline approaching batch_id, current_stage, remaining_stages, est_completion, doc_status Prioritize batch → Accelerate QC → Expedite packaging
Energy cost spike energy_kwh, solar_pct, gas_usage, cost_per_kg, efficiency_metric Shift to solar → Optimize drying schedule → Review equipment
