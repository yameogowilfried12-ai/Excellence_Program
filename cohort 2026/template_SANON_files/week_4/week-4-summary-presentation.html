HARVEST_EVENT Data Schema

Field Name Data Type Required Description
harvest_id String (UUID) Yes Unique identifier for harvest event
batch_id String (Alphanumeric) Yes Batch identifier for traceability
harvest_date Date (ISO 8601) Yes Date of harvest
mango_variety String (Enum) Yes Mango variety code (KEITT, KENT, TOMMY, AMÉLIE)
farm_id String (Code) Yes Farm identifier
block_id String (Code) Yes Farm block identifier
harvest_quantity_kg Number (Decimal) Yes Total harvest quantity in kilograms
quality_grade String (Enum) Yes Quality grade code (A, B, C, D)

Integration Mechanism

Pattern: Event-Driven Asynchronous Integration

MVP Recommendation: REST API (GET /api/v1/harvest-events/{harvest_id})

Production Target: Message Queue (Topic: harvest.events)

Trigger: Harvest recorded in Plants system

Integration Objectives

  • Enable complete traceability from harvest to final product
  • Enable Product Transformation to plan processing capacity
  • Ensure quality grade information is preserved
  • Reduce manual data entry and errors
  • Enable just-in-time processing scheduling

The data integration specification ensures interoperability while maintaining system independence through asynchronous patterns.

Forecasting Methodology

Selected Method: 3-Year Simple Moving Average with Seasonal Adjustment

Rationale: Transparency, Simplicity, Explainability, Reproducibility

Algorithm:

  1. Calculate 3-year moving average for each week
  2. Apply seasonal factor (2023 total / 2022 total = 1.046)
  3. Apply quality grade distribution (A: 63.0%, B: 27.0%, C: 10.0%)

Forecasting vs. Actual Processing

IMPORTANT DISTINCTION:

  • Forecasting: Separate planning activity that influences capacity planning and resource scheduling
  • Actual Processing: Uses actual received harvest data, not predicted values
  • Status: SPECIFIED / DESIGNED — NOT YET IMPLEMENTED

The forecasting capability is specified and designed in Week 4, but implementation is deferred to future weeks. This follows the principle of avoiding premature complexity.
