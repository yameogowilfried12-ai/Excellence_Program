Hardware, Connectivity & Field Constraints

Network loss (Wi-Fi / 4G)

The IoT gateway keeps running the already-planned cycles locally and logs every action to embedded storage (edge storage). On reconnection, deferred synchronization pushes the full history to the backend and reconciles states.

Power outage

Solenoid valves are wired "normally closed": an outage closes the circuit by default rather than letting an irrigation cycle continue unsupervised. When power returns, the system requires a valid level reading before restarting a cycle.

Failure blocking an installation visit

When a failure (vehicle, tooling, on-site power) prevents the planned technical visit, the site is never marked "operational" by default: it stays "installation pending" until commissioning is actually confirmed, and the visit is automatically rescheduled.

Site inaccessible (weather, safety, access)

An intervention is never forced if access is dangerous or blocked: the postponement is logged with a reason and is not counted as an unjustified missed visit in tracking metrics.

Sensor stuck on an implausible value

A value outside the physical range (e.g., humidity < 0% or > 100%, pH > 14) is rejected at ingestion and treated as missing data, not as a real measurement.

Reconnection & synchronization

Every local record carries its original timestamp; deferred synchronization respects the true chronological order so that KPIs and the alert history stay consistent after a prolonged outage.

Zone Arbitration Policy

When the water supply is insufficient, the scheduler applies a fixed priority by zone criticality rather than a global shutdown. The table below illustrates the rule applied according to reservoir level.

Reservoir levelZone A — fragile cropsZone B — standard cropsZone C — lawn / non-essential
> 40% (Normal)100%100%100%
20 – 40% (Vigilance)100%70%40%
< 20% (Critical)100% if justifiedQueued0%
A zone that is "queued" is never cancelled: it resumes automatically as soon as the reservoir rises back above the threshold, in the priority order defined above.

Nominal vs Edge Case — Rain During an Active Cycle

Scenario SC-12

Nominal path: the irrigation cycle starts, runs according to plan, and completes normally.

Edge case: sudden heavy rain occurs during an active cycle (rainfall rate > 10 mm/h detected). The backend immediately stops the active cycle, logs the volume actually delivered (rather than the planned volume) in the KPI engine, and recalculates the day's schedule to account for the natural water input.
