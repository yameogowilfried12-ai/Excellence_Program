Step 1: Data Model Foundation

The data model defines what information the system stores. These entities form the backbone of the application.

BATCH

Core Entity

The traceable thread that ties everything together

  • batch_id
  • lot_code
  • status
  • current_stage
  • input_weight
  • final_weight

Stage Records

Process Data

One record per stage per batch

  • WASH_SORT_RECORD
  • DRYING_RUN
  • PACKAGING_RECORD

QC & Compliance

Cross-cutting

Quality and safety across all stages

  • QC_CHECKPOINT
  • COMPLIANCE_RECORD
  • CCP monitoring

Master Data

Reference

Static data that drives processes

  • FARM
  • RAW_INTAKE
  • EQUIPMENT
  • OPERATOR
03

Step 2: User Roles

Who uses the system? Each role has specific permissions and responsibilities based on their workflow needs.

Product Transformation Manager

Strategic

Overall oversight, KPI monitoring, decision support

  • View all batches
  • Monitor KPIs
  • Approve releases
  • Access reports

Wash Station Operator

Operational

Executes washing and sorting, records data

  • Create WASH_SORT_RECORD
  • Record water quality
  • Track yield

Drying Operator

Operational

Manages drying process, monitors parameters

  • Create DRYING_RUN
  • Monitor temp/moisture
  • Select energy source

QC Inspector

Quality

Performs quality checks at each stage

  • Create QC_CHECKPOINT
  • Record pass/fail
  • Trigger corrective actions

Packaging Operator

Operational

Packages products, generates labels

  • Create PACKAGING_RECORD
  • Generate lot codes
  • Print labels

Compliance Auditor

Compliance

Ensures HACCP and EU compliance

  • Create COMPLIANCE_RECORD
  • Verify CCPs
  • Audit trails
